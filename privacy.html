隐私政策

更新日期：2026-10-07

本政策说明 WorkHub-RS 在用户自行部署、配置和授权后如何处理 Google 用户数据及相关工作记录。应用由个人维护，运行在使用者自己的工作环境中。

访问哪些信息

  • 登录信息：Google 账号邮箱、授权状态和识别授权账号所需的基本信息。
  • 资料内容：用户提供或工作消息引用的 Google 文件、文档和工作表的标题、内容及来源链接。Drive 只读授权允许读取和下载账号有权访问的文件，实际读取由工具接收到的链接和任务决定。
  • 表格信息：任务相关的工作表内容、目标单元格及操作回执。Sheets 读写授权用于用户已配置并授权的表格状态更新。

如何使用这些信息

这些信息用于读取工作资料、分析用户的问题、整理需求与任务、记录进度、生成用户需要的摘要或文案，以及执行用户允许的表格状态更新。程序保留来源和执行回执，便于用户核对结果。

AI 服务与其他数据接收方

启用 AI 分析时，程序会将完成当前请求所需的消息、资料内容或摘录发送给用户在本机配置的模型服务。启用通知或协作功能时，必要摘要、文案或执行结果可能发送到用户配置的消息渠道或工作服务。具体服务及其数据保留方式取决于用户的配置、账号设置和相应服务条款。

WorkHub-RS 本身不提供出售 Google 用户数据、利用这些数据投放广告或训练通用模型的功能。使用者配置外部服务时，应确保其处理方式符合 Google 的有限使用要求；不能把取得的 Google 资料用于与已披露工作功能无关的用途。

本机保存与保护

文档缓存、任务记录、来源引用和必要运行日志保存在用户本机的工作区，并可能进入本机备份。Google 访问令牌与刷新令牌在当前 Windows 实现中使用 DPAPI 加密保存；必要的账号标识和保存时间用于显示连接状态。OAuth 客户端配置单独存放于本机凭据目录。授权令牌不作为 AI 提示内容发送。

公开说明页面不要求用户输入 Google 密码，也不接收本机的授权令牌或工作资料。页面托管服务可能为运行和安全目的记录普通访问日志，其处理方式以托管服务的隐私说明为准。

保留、撤销与删除

本机资料与记录会保留到用户主动清理，或按照其配置的维护规则清理为止；备份有独立的保留设置。用户可以在 Google 账号的第三方连接管理中撤销授权，并退出本机 Google 连接。

撤销授权会阻止后续的相应 API 访问，但不会自动清除已经保存在本机或备份中的内容。停用后，用户可以清理对应工作区与备份；已发送到所配置外部服务的信息，按该服务的处理和删除规则管理。需要帮助时可联系应用支持邮箱。

Google 数据使用规则

WorkHub-RS 对通过 Google API 获取的信息的使用与转移，应遵守 Google API Services User Data Policy及其 Limited Use 要求，并遵守 Google Workspace 用户数据和开发者政策。Google 授权不改变文件本身的共享或编辑权限。

政策更新与联系

影响 Google 数据用途、访问范围或共享方式的变更，应先更新相关说明，并在需要时重新取得用户授权。本页顶部标明说明更新日期。
